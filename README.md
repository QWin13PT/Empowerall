# EMPOWERALL

Multilingual marketing landing page for the EMPOWERALL project (en / pt-PT).

## Stack

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4 (`@theme` tokens)
- next-intl
- Motion (`motion/react`)

## Scripts

```bash
npm run dev
npm run check
```

`check` runs lint, typecheck, i18n key sync, and production build.
